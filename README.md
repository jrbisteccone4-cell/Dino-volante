# Echoes of Strata

**Echoes of Strata** è un gioco d'azione e puzzle in 3D che unisce esplorazione geologica e manipolazione temporale. 

## 🌟 Caratteristiche Principali
* **Stratigrafia Temporale:** Modificare l'ambiente nel presente altera la conformazione fisica del passato e del futuro.
* **Eco Sonoro:** Utilizzo di onde acustiche tridimensionali per risolvere enigmi e scoprire percorsi nascosti.
* **Fisica Dinamica:** Interazione tra oggetti attraverso le ere geologiche.

## 🕹️ Comandi di Gioco
* `1` - Passa allo strato del **Passato**
* `2` - Passa allo strato del **Presente**
* `3` - Passa allo strato del **Futuro**
* `Spazio` - Emetti un **Eco Sonoro** di scansione

## 🛠️ Tecnologie Utilizzate
* **Engine:** Unity (C#)
* **Genere:** Puzzle / Azione / 3D
